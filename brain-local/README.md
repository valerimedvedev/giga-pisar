# Мозг Писаря на своём компьютере

Нейронка, которая причёсывает надиктованное, может жить не на сервере
сайта и не в браузере, а **отдельной программой на компьютере человека**.
Страница (пробная `web/` или плагин WordPress) обращается к ней по
`http://127.0.0.1:8091`, текст на сайт не уходит, а сервер сайта ничего
не считает. На компьютере с 32 ГБ памяти это быстрее и сервера, и
браузера, и модель можно поставить любую.

Годится любая программа с OpenAI-совместимым API:

| Программа | Порт | Как разрешить странице доступ |
|---|---|---|
| **brain-local** (этот установщик: llama-server + модель) | 8091 | ключ доступа печатается при запуске |
| [Ollama](https://ollama.com) | 11434 | переменная `OLLAMA_ORIGINS=https://ваш-сайт` (или `*`) |
| [LM Studio](https://lmstudio.ai) | 1234 | в настройках сервера включить CORS |
| llama-server вручную | 8080 | `--api-key` по желанию |

Страница сама ищет мозг на этих портах (кнопка «Найти / проверить»).

## Установка brain-local

**Windows** (PowerShell):
```powershell
powershell -ExecutionPolicy Bypass -File install.ps1                  # GigaChat
powershell -ExecutionPolicy Bypass -File install.ps1 -Model qwen3-14b
powershell -ExecutionPolicy Bypass -File install.ps1 -Backend vulkan  # на видеокарте
```
Появится ярлык «Мозг Писаря» на рабочем столе. Всё лежит в `%LOCALAPPDATA%\GigaBrain`.

**macOS / Linux**:
```bash
bash install.sh              # GigaChat
bash install.sh qwen3-14b
~/.giga/brain/start.sh       # запуск
```

При запуске программа печатает адрес и **ключ доступа**. На странице:
⚙ Мозг → «Нейронка на моём компьютере» → адрес, ключ → «Найти / проверить» →
выбрать модель → «Сохранить». Выбор запоминается в этом браузере.

## Модели

Список в `catalog.json`:

| id | Модель | Файл | Памяти | Про что |
|---|---|---|---|---|
| `gigachat` | GigaChat 3.1 10B-A1.8B | 6,5 ГБ | 12 ГБ | родной русский, быстрая (MoE), **по умолчанию** |
| `qwen3-4b` | Qwen3-4B Instruct | 2,5 ГБ | 6 ГБ | лёгкая, как в браузере |
| `qwen3-8b` | Qwen3-8B | 5 ГБ | 10 ГБ | умнее 4B |
| `qwen3-14b` | Qwen3-14B | 9 ГБ | 16 ГБ | лучшее качество для 32 ГБ |
| `yandexgpt-5-lite` | YandexGPT 5 Lite 8B | 5 ГБ | 10 ГБ | родной русский, от Яндекса |
| `gemma3-12b` | Gemma 3 12B | 7,3 ГБ | 14 ГБ | сильна в переводе |

Любой другой `.gguf`: `install.ps1 -ModelUrl <адрес>` / `install.sh --url <адрес>`.
Через Ollama ещё проще: `ollama pull hf.co/ai-sage/GigaChat3.1-10B-A1.8B-GGUF:Q4_K_M`
и модель появится в списке на странице.

> Ссылки в каталоге ведут на Hugging Face; из среды, где писался установщик,
> Hugging Face недоступен, поэтому имена файлов стоит проверить при первом
> запуске. Если файл переименовали, укажите адрес через `-ModelUrl`.

## Что нужно знать

- **Безопасность.** Мозг слушает только `127.0.0.1` и требует ключ. Без ключа
  любая открытая вкладка могла бы гонять вашу нейронку.
- **Браузеры.** Chrome, Edge, Яндекс Браузер и Firefox пускают страницу с https
  на `http://127.0.0.1`. Новые Chrome спрашивают разрешение «доступ к устройствам
  в локальной сети» — нажмите «Разрешить». Safari такой доступ блокирует.
- **Промпты и команды** приходят со страницы (для WordPress — из настроек
  плагина), модель на компьютере получает их такими же, как сервер.
