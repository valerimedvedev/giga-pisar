# Мозг Писаря на своём компьютере — GigaBrain

Нейронка, которая причёсывает надиктованное, может жить не на сервере
сайта и не в браузере, а **отдельной программой на компьютере человека**.
Страница (пробная `web/` или плагин WordPress) обращается к ней по
`http://127.0.0.1:8091`, текст на сайт не уходит, сервер сайта ничего не
считает. На компьютере с 32 ГБ памяти это быстрее и сервера, и браузера,
и модель можно поставить любую.

## GigaBrain — один файл

`dist/GigaBrain.exe` (Windows, окно), `GigaBrain-macos-arm64` / `-intel`,
`GigaBrain-linux-x64` (консоль). Ничего ставить не нужно.

### Windows: окно

Первый запуск — маленькое окно «Первый запуск»: где считать (процессор /
Vulkan / CUDA), какую нейронку скачать первой, ставить ли автозапуск →
«Установить». Дальше всё видно в одном компактном окне:

* **Статус** сверху: «● Мозг слушает http://127.0.0.1:8091 · GigaChat 3.1 готова».
* **Адрес** и **ключ доступа** с кнопками «Копировать» (ключ скрыт точками, «Показать»).
* **Нейронки на этом компьютере** — таблица (модель, размер, состояние: основная /
  работает / запускается) и кнопки «Сделать основной», «Скачать ещё…» (каталог
  с размером и потребной памятью, поле для своего адреса .gguf), «Удалить», «Папка моделей».
* **Настройки**: считать на (смена сборки llama.cpp по кнопке «Переустановить движок»),
  порт, потоки, контекст → «Применить»; галочки **«Запускать при входе в Windows»**
  (реестр HKCU\…\Run, запуск свёрнутым) и «Закрытие окна прячет мозг в область
  уведомлений»; **папка данных** с кнопками «Открыть» и «Перенести…» (движок,
  нейронки и настройки переезжают на другой диск, программа запоминает новое место).
* **Протокол** — что происходит: скачивание с процентами и скоростью, запуск
  нейронок, ошибки. Кнопка «Выключить мозг».

Значок в области уведомлений: клик — открыть окно, правый клик — «Открыть окно» /
«Выключить мозг». При первом запуске программа копирует себя в папку данных
(`%LOCALAPPDATA%\GigaBrain`) и делает ярлык «Мозг Писаря» на рабочем столе.

Сборку llama.cpp GigaBrain выбирает по ключевым словам в именах файлов выпуска
(схема имён у llama.cpp меняется), перебирая несколько последних выпусков. Если
ничего не подошло — окно со списком файлов выпуска, выбрать вручную.

### macOS и Linux: консоль

Запустили — спросит, где считать, покажет каталог и скачает выбранную нейронку.
Меню по буквам: `m` основная модель · `a` скачать ещё · `k` показать ключ ·
`l` каталог · `q` выход. Данные в `~/.giga/brain`.

### На странице

**⚙ Мозг → «Нейронка на моём компьютере» → адрес и ключ → «Найти / проверить» →
выбрать модель → «Сохранить»**. Выбор запоминается в браузере. Можно скачать
несколько нейронок: страница видит их все (`/v1/models`), а GigaBrain при
запросе сам поднимает нужную.

Ключи командной строки (общие):
```
GigaBrain.exe --tray                  запуститься свёрнутым (так делает автозапуск)
GigaBrain.exe --add qwen3-30b-a3b     скачать модель из каталога
GigaBrain.exe --add https://…/x.gguf  любой .gguf по адресу
GigaBrain.exe --model gigachat-20b-a3b  основная модель
GigaBrain.exe --backend vulkan        cpu | vulkan | cuda
GigaBrain.exe --port 8091 --dir D:\GigaBrain --catalog my.json
GigaBrain.exe --llama-url https://…/llama-….zip   свой архив llama.cpp, если подбор не справился
GigaBrain-linux-x64 --list --no-menu  (консоль)
```

Сборка из исходников: `bash brain-local/build.sh` (Go 1.24+; библиотека окна
`github.com/lxn/walk` скачивается при первой сборке; иконка и манифест —
`gigabrain/res/`, готовые `.syso` уже в репозитории).

## Каталог нейронок

Всё, что удобно крутить локально для правки русского текста. Каталог
(`catalog.json`) GigaBrain берёт свежий с GitHub, без сети — встроенный.

| id | Модель | Файл | Памяти | Скорость на CPU | Про что |
|---|---|---|---|---|---|
| `gigachat3.1-10b` | **GigaChat 3.1 10B-A1.8B** (Сбер) | 6,5 ГБ | 12 ГБ | быстрая | родной русский, лучше всех правит русский текст; **по умолчанию** |
| `gigachat-20b-a3b` | GigaChat 20B-A3B (Сбер) | 12,7 ГБ | 20 ГБ | быстрая | старшая GigaChat — лучший русский для 32 ГБ |
| `yandexgpt-5-lite-8b` | YandexGPT 5 Lite 8B (Яндекс) | 5 ГБ | 10 ГБ | средняя | родной русский, деловой стиль |
| `t-pro-2.0-32b` | T-pro 2.0 32B (Т-Банк) | 19,8 ГБ | 26 ГБ | медленная | сильная русская, для видеокарты от 24 ГБ |
| `vikhr-nemo-12b` | Vikhr Nemo 12B | 7,5 ГБ | 14 ГБ | средняя | русская дообучка Mistral, держит стиль |
| `qwen3-4b` | Qwen3-4B Instruct | 2,5 ГБ | 6 ГБ | быстрая | лёгкая, как в браузере |
| `qwen3-8b` | Qwen3-8B | 5 ГБ | 10 ГБ | средняя | умнее 4B |
| `qwen3-14b` | Qwen3-14B | 9 ГБ | 16 ГБ | медленная | лучший плотный Qwen для 32 ГБ |
| `qwen3-30b-a3b` | **Qwen3-30B-A3B Instruct** | 18,6 ГБ | 24 ГБ | быстрая | ум 30B при скорости 3B — отличный выбор для 32 ГБ |
| `gemma3-4b` | Gemma 3 4B (Google) | 2,5 ГБ | 6 ГБ | быстрая | для ноутбуков |
| `gemma3-12b` | Gemma 3 12B (Google) | 7,3 ГБ | 14 ГБ | средняя | сильна в переводе |

**Для 32 ГБ и процессора** лучший баланс: GigaChat 20B-A3B или Qwen3-30B-A3B
(обе «мозг большой, считает как маленький»). С видеокартой от 16 ГБ можно
брать любые.

> Ссылки ведут на Hugging Face; из среды, где писалась программа, Hugging Face
> недоступен, поэтому точные имена файлов не проверены. Если файл переименовали,
> GigaBrain скажет «файла нет по адресу», а вы укажете адрес `.gguf` через
> `--add`. Каталог правится на GitHub без пересборки программы.

## Другие программы

Годится любая с OpenAI-совместимым API — страница ищет их сама:

| Программа | Порт | Как разрешить странице доступ |
|---|---|---|
| **GigaBrain** | 8091 | ключ доступа печатается при запуске |
| [Ollama](https://ollama.com) | 11434 | `OLLAMA_ORIGINS=https://ваш-сайт` (или `*`); модели: `ollama pull hf.co/ai-sage/GigaChat3.1-10B-A1.8B-GGUF:Q4_K_M` |
| [LM Studio](https://lmstudio.ai) | 1234 | в настройках сервера включить CORS |
| llama-server вручную | 8080 | `--api-key` по желанию |

Скрипты `install.ps1` / `install.sh` — прежний способ (один llama-server с одной моделью), оставлены на всякий случай.

## Что нужно знать

- **Безопасность.** Мозг слушает только `127.0.0.1` и требует ключ.
- **Браузеры.** Chrome, Edge, Яндекс Браузер и Firefox пускают страницу с https на
  `http://127.0.0.1`. Новые Chrome спрашивают разрешение «доступ к устройствам в
  локальной сети» — нажмите «Разрешить». Safari такой доступ блокирует.
- **SmartScreen.** Exe не подписан: при первом запуске Windows покажет «Неизвестный
  издатель» — «Подробнее → Выполнить в любом случае».
- **Промпты и команды** приходят со страницы (для WordPress — из настроек плагина).
