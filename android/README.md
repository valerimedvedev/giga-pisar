# Гига Писарь Диктовка — Android

Одно приложение для телефона (проверено в расчёте на Samsung Galaxy S23 Ultra,
подойдёт любой arm64 с Android 10+): поле ввода, диктовка в него и обработка
нейросетями — всё то, что делают плагин WordPress и GigaBrain вместе, только
внутри одного приложения и без сайта.

## Что умеет

* **Запись** — речь распознаётся на телефоне пакетом GigaAM v3 (Сбер, 213 МБ,
  скачивается с согласия при первой диктовке). Звук никуда не уходит. Текст
  встаёт туда, где стоял курсор; выделенное заменяется.
* **Скорость.** Фразы распознаются *во время* речи: как только человек делает
  паузу, фраза уходит в распознавание и появляется в поле, пока он говорит
  следующую. После «Стоп» ждёт только последняя фраза (доли секунды на S23
  Ultra). Модель прогревается при запуске, держится в памяти, декодер идёт
  в один поток без лишней раздачи работы. Порт ядра проверен на JVM: на всех
  21 записи текст совпадает с питоновским ядром буква в букву.
* **Мозг** — те же семь функций и промпты, что в плагине («Причесать»,
  «Исправить ошибки», «Сократить», «Собрать мысль», «Сгладить», «Деловой
  стиль», «Перевести на английский»), команды редактируются; голосовые
  команды в конце диктовки: «…, Писарь, сократи»; работа над выделенным или
  над всем текстом; **свой промпт с историей до 100** (📌 закреплённые не
  вытесняются; 101-й выталкивает самый старый незакреплённый); «Вернуть как было».
* **Где считает нейронка** (Настройки → Мозг):
  * *на телефоне* — llama.cpp внутри приложения; каталог моделей под телефон:
    Qwen3-4B (по умолчанию), Qwen3-1.7B (самая быстрая), Gemma 3 4B,
    GigaChat 3.1 10B-A1.8B, YandexGPT 5 Lite 8B, плюс любой свой .gguf с телефона;
  * *на компьютере* — GigaBrain (в окне включить «Доступ с телефона по домашней
    сети»), Ollama, LM Studio; кнопка «Найти в сети» сама находит GigaBrain;
  * *на сервере* — GigaChat или любой OpenAI-совместимый адрес.
* Копировать, отправить (в любое приложение), очистить.

## Сборка

Собрать можно только на компьютере с Android SDK (Android Studio): в облаке,
где писался код, доступа к SDK Google нет, поэтому **APK в репозитории нет** —
его делает `STAT-ANDROID.md` (задание для сессии STAT) или сам разработчик:

1. Android Studio (Ladybug или новее) → *Open* → папка `android/`.
2. SDK Manager: Android SDK Platform 35, NDK (side by side) 27.x, CMake 3.22.1.
   Нужен `git` в PATH: llama.cpp скачивается при первой сборке (закреплённый
   выпуск v0.5.0; свой путь — `-DLLAMA_DIR=…` в `app/build.gradle.kts` →
   `externalNativeBuild.cmake.arguments`).
3. *Build → Build App Bundle(s) / APK(s) → Build APK(s)* или в терминале:
   ```bash
   ./gradlew :app:assembleRelease
   # → app/build/outputs/apk/release/app-release.apk
   ```
   Release подписан отладочным ключом — для установки себе этого достаточно.
4. Установить на телефон: `adb install app-release.apk` или скопировать APK и
   открыть (разрешить установку из этого источника).

## Проверка ядра без Android

Модуль `engine/` — чистый Kotlin, зависит только от onnxruntime, собирается и
проверяется на любом компьютере с JDK 17+:

```bash
cd android
GIGA_MODEL=/путь/к/папке-модели GIGA_WAV=/путь/к/записям ./gradlew :engine:test
```

В папке записей нужен `ref_transcripts.json` (имя → расшифровка питоновским
ядром). Без переменных прогоняются только тесты команд, tar и докачки.

## Устройство

```
engine/   Features (лог-мел, float32 как в numpy) · Tokenizer (SentencePiece)
          Rnnt (энкодер/декодер/джойнт, жадный RNN-T) · Chunker + LiveChunker
          Brain (промпты, команды, «Писарь, …») · OpenAiChat · Downloader · Tar · Catalog
app/      PisarViewModel (сессия диктовки, мозг, скачивания, настройки)
          Mic (AudioRecord 16 кГц) · LocalLlm (JNI) · Store (настройки, история промптов)
          Models (файлы) · ui/ (Compose: экран, панель мозга, настройки)
          cpp/pisar_llm.cpp (llama.cpp: одна пара сообщений → ответ, шаблон чата модели)
```

Тот же пакет `ai.onnxruntime` работает на JVM и на Android, поэтому ядро
проверено сверкой с питоновским `server/giga_core.py` до полного совпадения.
Код Compose-экранов дополнительно проверен компилятором на JVM (Compose
Desktop с теми же пакетами `androidx.compose.*`).
