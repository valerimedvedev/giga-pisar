# Гига Писарь для Windows

Одна программа со всем, что умеет приложение для Android, плюс диктовка
**в любое окно Windows** по горячей клавише. Один файл, ничего ставить не нужно:
`dist/GigaPisar.exe` (Windows 10/11) или `dist/GigaPisar-win7.exe` (Windows 7, 8, 8.1).

## Что умеет

* **Режимы** (список вверху): *Диктовка* — в поле программы; *Диктофон* — длинная
  запись по частям в wav (пауза / продолжить, абзацы по паузам длиннее 2,5 с,
  список записей: «В текст», папка, удалить); *Общение* — беседа с нейронкой,
  вопрос можно надиктовать. Фразы распознаются во время речи, после «Стоп»
  ждёт только последняя.
* **Диктовать в любое окно**: горячая клавиша (по умолчанию **Ctrl+Alt+Space**,
  меняется в настройках) в любой программе — Word, браузер, мессенджер, блокнот.
  Нажали — запись в это окно, ещё раз — стоп; текст встаёт по курсору через буфер
  обмена (прежнее содержимое буфера возвращается). Плавающая полоска статуса внизу
  экрана. Выделили текст и нажали — команда голосом над выделенным («сократи»,
  «переведи на английский»). В конце диктовки: «…, Писарь, исправь».
* **🧠 Мозг** — панель справа от текста: те же семь команд, что в плагине и в
  Android (редактируются, до 10), область — выделенное или весь текст, **свой промпт**
  (Ctrl+Enter) с историей до 100 и 📌, «Вернуть как было».
* **Где считает нейронка** (Настройки → Мозг): на этом компьютере (llama.cpp
  внутри Писаря, каталог моделей GigaBrain, свой .gguf), GigaBrain / Ollama /
  LM Studio по адресу, сервер, облачный сервис с бесплатным тарифом (Gemini,
  Groq, OpenRouter, Mistral, Hugging Face, Cloudflare) с импортом набора ключей
  `giga-keys.json`.
* **Экспорт**: Файл → Word (.docx), Markdown (.md), текст (.txt); копировать всё.
* Значок в области уведомлений, автозапуск при входе, запуск свёрнутым (`--tray`).
* Первая диктовка спрашивает согласие скачать среду распознавания и пакет GigaAM v3
  (213 МБ) в папку данных `%APPDATA%\GigaPisar`. Звук никуда не уходит.

## Windows 7

`GigaPisar-win7.exe` собран Go 1.20 (последняя версия с поддержкой Windows 7)
и по версии системы сам скачивает onnxruntime 1.12.1 — последний, что запускается
на Windows 7/8; модели GigaAM (opset 17) с ним работают. На Windows 7 нужны
обновления с Universal CRT (KB2999226). Нейронка «на этом компьютере» через
свежие сборки llama.cpp на Windows 7 не запустится — там мозг через GigaBrain
на другом компьютере, сервер или облако.

## Устройство и проверка

```
ort/       onnxruntime без cgo: библиотека грузится динамически, функции — из таблицы OrtApi
asr/       признаки, токенизатор, RNN-T, нарезка, wav — порт ядра (сверен с Python: 21 из 21)
brain/     промпты, команды «Писарь, …», облачные пресеты, набор ключей, OpenAI-клиент, история
localllm/  llama-server внутри программы (движок и модели — как в GigaBrain)
core/      логика без окна: сессия диктовки в цель, диктофон, мозг, общение (тесты на Linux)
win/       waveIn-микрофон, буфер обмена + SendInput, горячая клавиша, автозапуск, версия Windows
gui_windows.go / settings_windows.go / overlay_windows.go — окно (walk), настройки, плавающий статус
```

Проверка ядра на Linux: `CGO_ENABLED=0 go test ./...` и сверка распознавания с
питоновским ядром: `go run ./cmd/asrtest <libonnxruntime.so> <папка модели> <папка wav>`.
Само окно проверяется только на Windows.

Сборка: `bash windows/build.sh` (Go 1.24+; Go 1.20.14 для варианта win7 подтянется
сам). Готовые exe собирает GitHub Actions в выпуск `windows-latest`.
