=== Гига Писарь — голосовой ввод ===
Tags: voice, dictation, speech recognition, русский, диктовка
Requires at least: 6.2
Tested up to: 6.5
Requires PHP: 7.4
Stable tag: 1.0.0
License: MIT

Диктовка голосом в любое поле ввода и в редакторы WordPress. Речь распознаётся в браузере — звук никуда не уходит.

== Description ==

* Курсор встал в поле ввода (textarea, текстовое поле, contenteditable) — у его края появляется кнопка микрофона. Нажали — запись, нажали ещё раз — текст с пунктуацией встаёт туда, где стоял курсор.
* Кнопка «Диктовка» в панели форматирования блочного редактора (меню «Ещё» у блока) и классического редактора (TinyMCE).
* Первая диктовка спрашивает согласия скачать пакет распознавания речи GigaAM v3 (213 МБ) в браузер. Дальше он работает оттуда, без повторных загрузок. Звук не покидает компьютер.
* Мозг Писаря — очистка речи нейронкой (слова-паразиты, оговорки, ошибки распознавания) и команды: «…, Писарь, исправь / сократи / переведи на английский» в конце диктовки, команда над выделенным текстом, кнопки «Причесать», «Сократить», «Перевести», «Вернуть как было». Включает и выключает только администратор; он же решает, кому мозг доступен (по умолчанию — только администраторам). Остальные пользуются прямой диктовкой.
  * Qwen3-4B — в браузере человека (1,9 ГБ, скачивается с его согласия).
  * GigaChat — на сервере (llama-server). Браузеры ходят к нему только через REST WordPress: с проверкой прав, своим промптом и лимитом 12 правок в минуту.

Настройки — пункт «Гига Писарь» в меню администратора: вкладки «Диктовка», «Мозг», «Модели на сервере».

== Installation ==

1. Плагины → Добавить новый → Загрузить плагин → giga-pisar-1.0.0.zip → Активировать.
2. Гига Писарь → Модели на сервере → «Скачать на сервер» у пакета распознавания (сервер скачает его с GitHub в uploads/giga-pisar/). Без этого посетители выбирают архив со своего диска: браузер не может скачать его с GitHub сам.
3. По желанию: вкладка «Мозг».

Сайт должен работать по https — иначе браузер не даст микрофон.

== Frequently Asked Questions ==

= Какие браузеры? =
Проверено в Chromium (Chrome, Edge, Яндекс Браузер). Firefox и Safari должны работать — нужны WebAssembly, AudioWorklet и Cache Storage, — но пока не проверялись.

= Почему медленно? =
Без изоляции страниц распознавание идёт в один поток: 8 секунд речи — около 3 секунд. Галочка «Многопоточность» на вкладке «Диктовка» ускоряет в 2–3 раза, но добавляет заголовки COOP/COEP — проверьте, что сайт с ними работает.
