# Гига Писарь — надстройка для Word

Боковая панель в Word с тем же, что делает плагин WordPress: 🎙 **Запись**
(речь распознаётся пакетом GigaAM v3 прямо в Word, звук никуда не уходит)
и 🧠 **Мозг** (правка нейронкой). Это обычная надстройка Office: страница
`taskpane.html` живёт на сайте (`https://vmindlab.ru/pisar/word/`), Word
показывает её в панели справа и правит документ через Office.js.

## Что умеет — один в один с плагином

* Диктовка: нажали «Запись» — говорите — «Стоп»; текст встаёт туда, где
  курсор (вместо выделения, если оно было), с пробелами по краям при нужде.
  Esc — отмена. Пакет распознавания (213 МБ) скачивается один раз и остаётся в Word.
* Голосовые команды: «…текст, Писарь, сократи» в конце диктовки; выделили
  текст, нажали «Запись» и сказали команду — она выполнится над выделенным.
* Панель 🧠: где считает мозг и ⚙; **область работы** — выделенное, а без
  выделения абзац с курсором (замена всего документа убила бы оформление);
  команды на кнопках (те же семь, редактируются в ⚙, до 10); **свой промпт**
  (Ctrl+Enter) с историей до 100: 📌 закреплённые не вытесняются, клик подставляет,
  двойной клик выполняет; «Вернуть как было» (и обычный Ctrl+Z в Word тоже работает).
* Мозг — как на пробной странице: GigaChat на сервере сайта, Qwen3-4B в Word
  (1,9 ГБ, скачивается один раз) или **GigaBrain на этом компьютере** (адрес,
  ключ, «Найти / проверить», выбор модели). Промпты редактируются в ⚙.

Файлы: `manifest.xml` (описание надстройки для Word), `taskpane.html/css/js`
(панель), `doc.js` (чтение и правка документа через Office.js), `icons/`.
Ядро распознавания и мозг — общие с пробной страницей: `../giga/`.

## Выложить на сайт

`web/deploy/deploy.sh` копирует `word/` вместе со страницей в `/var/www/pisar/`,
nginx-сниппет уже содержит `location /pisar/word/` (без COOP/COEP: office.js
с CDN Microsoft под изоляцией не загрузится). Проверка: открыть
`https://vmindlab.ru/pisar/word/taskpane.html` в браузере — панель работает и
там (без Word кнопки правят ничего, но модель и мозг проверить можно).

## Подключить в Word (Windows)

Word для Windows не даёт «загрузить файл надстройки» кнопкой, нужен один из
двух путей:

**Реестр (одна команда PowerShell, без прав администратора):**
```powershell
$m = "$env:USERPROFILE\Downloads\manifest.xml"        # скачанный manifest.xml
New-Item -Path "HKCU:\Software\Microsoft\Office\16.0\WEF\Developer" -Force | Out-Null
Set-ItemProperty -Path "HKCU:\Software\Microsoft\Office\16.0\WEF\Developer" -Name "GigaPisar" -Value $m
```
Перезапустить Word → вкладка «Главная» → кнопка **«Гига Писарь»** (либо
Вставка → Надстройки → Мои надстройки → «Надстройки разработчика»).

**Общая папка (каталог доверенных надстроек):** положить `manifest.xml` в
папку, открыть к ней общий доступ (`\\ИМЯ-ПК\pisar`), в Word: Файл → Параметры →
Центр управления безопасностью → Параметры → Каталоги доверенных надстроек →
добавить путь, галочка «Показывать в меню» → перезапуск → Вставка → Мои
надстройки → «Общая папка».

Microsoft 365 в организации: администратор публикует `manifest.xml` через
центр администрирования (Интегрированные приложения) — тогда надстройка
появится у всех сама.

Word в браузере (office.com): Вставка → Надстройки → Ещё надстройки →
«Мои надстройки» → «Отправить мою надстройку» → manifest.xml.

## Ограничения

* Микрофон в панели работает в Word для Windows (движок WebView2, Office
  2021 / Microsoft 365) и в Word в браузере. В Word для Mac панель не получает
  микрофон — там останутся только команды мозга над выделенным.
* Нейронка на компьютере: панель обращается к `http://127.0.0.1:8091` как обычная страница; если Word такой запрос не пропускает, включите в GigaBrain «Доступ по домашней сети» и укажите адрес компьютера `http://192.168.…:8091`.
